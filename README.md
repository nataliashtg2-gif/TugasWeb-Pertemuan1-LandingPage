## Deskripsi
Landing page pribadi yang dibuat menggunakan HTML5 semantik tanpa CSS sebagai fondasi untuk pengembangan Tugas Rutin berikutnya.

## Requirement
- Minimal 5 semantic tags
- Struktur HTML5
- Form kontak dengan validasi HTML
- Elemen media
- Accessibility dengan `alt`, `label`, dan `aria-label`
- Navigasi internal
- Siap dikembangkan pada TR 2 menggunakan CSS

## Semantic Elements
`header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `figcaption`, dan `footer`.

## Cara Menjalankan
1. Extract ZIP.
2. Buka folder project di VS Code.
3. Buka `index.html`.
4. Klik kanan → **Open with Live Server**.

### Menggunakan XAMPP
XAMPP **tidak wajib** karena project ini hanya HTML. Namun, jika ingin konsisten dengan tugas web lainnya, letakkan folder di:

`C:\xampp\htdocs\TugasWeb-Pertemuan1-Natalia`

Lalu buka:

`http://localhost/TugasWeb-Pertemuan1-Natalia/`

MySQL tidak perlu dinyalakan.

## Catatan Foto
Project memakai gambar placeholder agar langsung dapat dijalankan. Untuk versi final, ganti `images/profile-placeholder.svg` dengan foto pribadi dan sesuaikan atribut `src` pada `index.html`.

## Pengembangan Berikutnya
TR 2 akan mengembangkan HTML ini menggunakan CSS tanpa mengubah fondasi konten utama.
